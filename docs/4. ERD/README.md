배치도는 같은 영역의 테이블 관계를 보여 준다. 화살표는 참조 대상에서 외래키를 가진 테이블을 향한다. 정보표에는 컬럼, 타입, 키, NULL 허용 여부, 기본값과 외래키의 참조 컬럼이 있다. 다른 영역으로 이어지는 외래키도 정보표에 정리했다. CHECK, 인덱스, 시퀀스의 전체 정의는 DDL을 확인한다.
