# 9. 발표자료 및 시연영상

- 넣는 것
  - 발표자료: `이음_발표자료.pdf`와 원본 `이음_발표자료.pptx`
  - 시연영상: 아래 5개 시나리오별 MP4. 파일 이름은 `이음_시연영상_<순번>_<시나리오>.mp4`로 맞춘다.
- 담당
  - 발표자료: 최준원·정상욱
  - 시연영상: 서장호
- 시연영상은 50MB 아래로 줄여 넣는다(GitHub는 50MB부터 경고하고 100MB가 넘으면 push를 거절한다). 해상도를 720p로 낮추거나 나눠도 안 되면 영상은 저장소 밖에 올리고 아래에 링크를 적는다.
