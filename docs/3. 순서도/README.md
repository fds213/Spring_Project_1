# 3. 순서도

- 넣는 것: 기능 흐름 순서도
- 담당: 각 담당이 맡은 기능의 순서도를 1장씩 내고, 최준원이 한 장으로 취합한다.
- 파일 이름
  - 각자 낸 것: `이음_순서도_<모듈>_<이름>.png`(예: `이음_순서도_근태_홍동국.png`)와 그린 도구의 원본(예: `이음_순서도_근태_홍동국.drawio`)
  - 취합본: `이음_순서도.png`(또는 `.pdf`)와 원본
- 업무 흐름의 기준은 계획서의 흐름 A·B·C와 요구분석서다. 화면에 없는 단계를 새로 그리지 않는다.

올리는 법·크기 제한·공개 저장소 주의는 [`docs/README.md`](../README.md)에 있다.
