# 3. 순서도

- 넣는 것: 기능 흐름 순서도
- 담당: 최준원이 한 장으로 만들고, 각 담당은 자기 모듈의 흐름이 화면과 같은지 확인한다(11/11). 근태(⑨)는 홍동국이 그린 순서도를 옮겼다.
- 파일
  - `이음_순서도.png`: 제출본. 흐름 13개(① 업체 도입 ~ ⑬ 문의)가 한 장에 있다. 기준은 `main` 태그 `v0.5`다.
  - `이음_순서도.html`: 원본. 브라우저로 열면 같은 그림이 나온다(Mermaid를 인터넷에서 받는다).
- 고치는 법: `이음_순서도.html` 안의 흐름 글(`flowchart LR` 아래 줄)을 고치고, 브라우저에서 연 화면을 PNG로 다시 저장해 같은 이름으로 덮어쓴다.
- 업무 흐름의 기준은 계획서의 흐름 A~E와 요구분석서 3장 '이번 구현 범위'다. 화면에 없는 단계를 새로 그리지 않는다.

올리는 법·크기 제한·공개 저장소 주의는 [`docs/README.md`](../README.md)에 있다.
