이음(IEUM) 순서도

업체용 그룹웨어 + 데모·구독 운영 플랫폼. 기준 main v0.5 (828695a, 2026-11-11). 업무 흐름의 기준은 프로젝트 계획서 3장(흐름 A~E)과 요구분석서 3장 '이번 구현 범위'다.

시작·끝처리(서버) 입력·안내(화면)판단DB 저장·조회

① 업체 도입 (무료 체험 신청 → 관리자 로그인)
