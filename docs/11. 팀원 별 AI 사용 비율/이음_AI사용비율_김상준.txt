== 김상준 담당업무 ==
   A. 프론트
   - 결재 첨부 화면(팀장 요청으로 맡음). 그 밖의 화면은 프론트 담당이 구현
   1. 결재 첨부 (글쓰기 파일 올리기, 결재함 첨부 목록)
          - 본인이 직접 구현 0%
          - AI가 구현 100%
          - AI가 구현 했지만 본인이 검토/이해한 부분 60%

   B. 백엔드
   - 사원(employee)·공통(common: 인증·권한·파일·만료 읽기 전용) 담당, 결재 첨부 추가
   1. 로그인·인증 (업체 코드+사번 로그인, 5회 실패 잠금, 401·403 처리, 역할 변경·비활성화 시 세션 끊기)
          - 본인이 직접 구현 25%
          - AI가 구현 75%
          - AI가 구현 했지만 본인이 검토/이해한 부분 60%
   2. 공통 기능 (첨부파일 저장·형식 검사, 상태 코드 enum, 만료 업체 읽기 전용, 헤더 정보·메뉴 배지)
          - 본인이 직접 구현 15%
          - AI가 구현 85%
          - AI가 구현 했지만 본인이 검토/이해한 부분 20%
   3. 직원 가입·승인 (가입 신청·취소, 승인·반려, 사번 발급, 인원 한도, 다른 모듈용 직원 조회)
          - 본인이 직접 구현 45%
          - AI가 구현 55%
          - AI가 구현 했지만 본인이 검토/이해한 부분 80%
   4. 사원 관리 (사원 목록, 부서장 지정, 비활성화·다시 사용, 부서·직급 관리, 퇴사 처리, 역할 변경, 조직도)
          - 본인이 직접 구현 10%
          - AI가 구현 90%
          - AI가 구현 했지만 본인이 검토/이해한 부분 85%
   5. 비밀번호 변경·찾기 (본인 비밀번호 변경, 메일 인증 코드로 재설정)
          - 본인이 직접 구현 10%
          - AI가 구현 90%
          - AI가 구현 했지만 본인이 검토/이해한 부분 80%
   6. 결재 첨부 (파일 올리기, 상신 때 문서에 연결, 결재함 목록, 권한 확인 내려받기, 테스트)
          - 본인이 직접 구현 10%
          - AI가 구현 90%
          - AI가 구현 했지만 본인이 검토/이해한 부분 20%
