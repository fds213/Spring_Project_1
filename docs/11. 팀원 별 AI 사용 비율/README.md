# 11. 팀원 별 AI 사용 비율

- 넣는 것: 한 사람당 txt 한 파일
- 담당: 각자
- 파일 이름: `이음_AI사용비율_<이름>.txt`(예: `이음_AI사용비율_최준원.txt`). 인코딩은 UTF-8.
- 맡은 기능마다 세 비율을 적는다. 받은 양식에는 합을 맞추는 법이 없어 팀은 이렇게 쓴다.
  - '본인이 직접 구현'과 'AI가 구현'의 합이 100%다.
  - 세 번째 'AI가 구현 했지만 본인이 검토/이해한 부분'은 AI가 구현한 부분 가운데 본인이 검토·이해한 비율이다. 세 값을 더해 100으로 맞추지 않는다.
  - 예: 직접 40%, AI 60%, 그 60% 가운데 검토·이해한 것이 절반이면 세 번째는 50%.
- 맡지 않은 영역(예: 프론트만 했으면 B·C)은 지운다.

## 양식(받은 원문 그대로)

```text
== OOO 담당업무 ==
   A. 프론트
   - 프론트 담당이라면 맡은 기능 기재
   1. 기능명
          - 본인이 직접 구현 00%
          - AI가 구현 00%
          - AI가 구현 했지만 본인이 검토/이해한 부분 00%

   B. 백엔드
   - 백엔드 담당이라면 맡은 기능 기재
   1. 기능명
          - 본인이 직접 구현 00%
          - AI가 구현 00%
          - AI가 구현 했지만 본인이 검토/이해한 부분 00%

   C. DB
   - DB 담당이라면 맡은 설계 기재
   1. 기능명
          - 본인이 직접 구현 00%
          - AI가 구현 00%
          - AI가 구현 했지만 본인이 검토/이해한 부분 00%
```

올리는 법·크기 제한·공개 저장소 주의는 [`docs/README.md`](../README.md)에 있다.
