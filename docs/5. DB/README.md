# 5. DB

- 넣는 것: 테이블정의서 `이음_테이블정의서.pdf`와 원본(`이음_테이블정의서.docx` 등)
- 담당: 정상욱
- DDL·DML 스크립트는 이 폴더에 복사하지 않는다. 두 곳에 두면 한쪽만 고쳐져 어긋난다. 제출본은 [`db/`](../../db/)에 있는 것이다.
  - DDL: [`db/ddl/IEUM_DDL.sql`](../../db/ddl/IEUM_DDL.sql)
  - DML(공통 코드 등): [`db/data/IEUM_COMMON_CODE_DML.sql`](../../db/data/IEUM_COMMON_CODE_DML.sql), 시연 자료 [`db/data/init_auth_data.sql`](../../db/data/init_auth_data.sql)·[`db/data/IEUM_DEMO_SEED.sql`](../../db/data/IEUM_DEMO_SEED.sql)
  - 실행 순서: [`db/README.md`](../../db/README.md)
- 마감 때 소스 코드 zip(`10. 요약본 및 소스 코드`)에 `db/`가 그대로 들어간다.

올리는 법·크기 제한·공개 저장소 주의는 [`docs/README.md`](../README.md)에 있다.
