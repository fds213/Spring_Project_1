회사에 필요한 기능을 한 번에

따로 쓰던 결재, 근태, IT 지원 도구를 하나로 합쳐 직원은 한곳에서 일하고, 관리자는 한곳에서 관리합니다.

전자결재

휴가·장비 신청을 순서대로 결재

결재자를 최대 2단계까지 지정해 차례로 승인·반려하고, 휴가가 최종 승인되면 연차와 일정에 자동으로 반영됩니다.

근태·연차

지문 단말기로 출퇴근 자동 기록

출입 지문 단말기의 기록을 받아 출근·퇴근, 지각·조퇴를 보여주고, 연차는 경력에 맞춰 자동으로 계산합니다. 지문 정보는 이음에 저장하지 않습니다.

IT 지원

장애 접수부터 처리까지

직원이 장애·문의를 접수하면 IT 담당자에게 배정되고, 처리 상태와 이력이 남습니다.

자산 관리

장비 지급·회수와 고장 이력

누구에게 어떤 장비가 지급됐는지, 어떤 장비가 자주 고장 나는지 한눈에 확인합니다.

일정·게시판

공지와 부서 소식, 일정 공유

공지·부서 게시판과 개인·부서·전사 일정을 권한에 맞게 함께 씁니다.

채팅

1:1·그룹 채팅

업무 대화를 사내에서 바로 나누고, 읽음 표시와 이전 대화도 확인합니다.

신청하면 바로 체험이 시작됩니다

신청하고 이메일을 인증하면 우리 회사 그룹웨어가 열립니다. 직원 계정은 관리자나 부서장이 가입을 열어 둔 동안 요청을 받아 승인하면 바로 만들어집니다.

  1. 무료 체험 신청업체 정보와 관리자 정보를 입력합니다. 결제는 없고, 관리자 포함 10명까지 써 볼 수 있습니다.
  2. 업체 개설업체 코드와 관리자 계정이 바로 만들어지고, 이메일 인증을 마치면 2주 체험이 시작됩니다.
  3. 직원 계정 만들기관리자가 가입을 열면 직원이 업체 코드로 계정 생성을 요청하고, 1시간 안에 승인하면 사번이 붙어 바로 로그인합니다.
  4. 2주 체험모든 직원이 모든 기능을 그대로 써 봅니다. 결제는 체험 중 언제든 할 수 있습니다.
  5. 결제하고 계속 이용그룹웨어 안에서 결제하고 운영자 승인을 받으면 그날부터 유료로, 계정과 데이터 그대로 이어서 씁니다.
가입은 관리자가 고른 부서(부서장은 자기 부서)만, 정한 시간(10분~하루) 동안 열립니다. 닫혀 있으면 업체 코드를 알아도 요청할 수 없습니다. 비밀번호를 잊으면 로그인 화면의 비밀번호 찾기에서 이메일 인증 뒤 다시 정합니다.
